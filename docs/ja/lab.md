# LAB出力

Voiceger Editorでは、採用したTakeの音声と一緒に、音素ごとの開始・終了時刻を記録したLABファイルを保存できます。

LABファイルは、リップシンクやアニメーション制作など、音声に合わせて動きを付ける用途で使用できます。

LAB出力は初期設定では無効です。

## 必要な環境

LAB出力を使用するには、追加のパッケージをインストールします。

VoicegerのPython環境を有効にした状態で、次のコマンドを実行してください。

```bash
python -m pip install "voiceger-editor[tui,lab]"
```

Voiceger Editor本体のセットアップについては、[セットアップ](setup.md)を参照してください。

### 日本語

日本語のLAB生成には、**Julius** が必要です。

Juliusの実行ファイルをインストールし、コマンドラインから使用できる状態にしてください。

音素の時刻合わせに使用する音響モデルは、初回使用時に自動でダウンロード・保存されます。そのため、初回のLAB生成にはインターネット接続が必要になる場合があります。

### 英語

英語のLAB生成には、**PocketSphinx 5.1.1** を使用します。

前述の `lab` オプション付きインストールで導入されます。

### Windowsでの注意点

Voiceger Editor 0.1では、Windows上のLAB出力は動作確認済みの対象に含まれていません。

PocketSphinx 5.1.1にはPython 3.9用のWindows向けビルド済みパッケージがなく、ソースからのビルドが必要になる場合があります。

また、Windows上でのJuliusによる日本語LAB生成も未検証です。

LABを使用しない通常の音声生成には、これらの追加環境は必要ありません。

## LAB出力を有効にする

1. `BATCH LIST`で`S`キーを押し、`EDIT SETTINGS`を開きます。
2. `[O] File format & naming` から `AUDIO OUTPUT` を開きます。
3. `[L] LAB` を `ON` に変更します。
4. `EDIT SETTINGS` に戻り、`[A] Apply and save` で保存します。

設定画面の詳しい操作については、[設定](settings.md)を参照してください。

起動時だけLAB出力を有効にする場合は、`--save-lab` を指定できます。

```bash
voiceger-editor --save-lab
```

反対に、一時的に無効にする場合は `--no-save-lab` を指定します。

## 保存されるファイル

LABファイルは、**Takeを採用したときに生成**されます。

例えば「今日は雨なのだ。」を読み上げたTakeを採用すると、次のように保存されます。

```text
202610020307_Neutral_今日は雨なのだ。.wav
202610020307_Neutral_今日は雨なのだ。.lab
```

TXT出力も有効にしている場合は、同じ名前のTXTファイルも保存されます。

```text
202610020307_Neutral_今日は雨なのだ。.txt
```

音声形式をFLACやMP3にしている場合も、LABファイルの保存方法は変わりません。

LABの生成には内部的にWAVを使用するため、保存する音声形式とは独立して動作します。

ファイル名や保存先の設定については、[設定](settings.md)を参照してください。

## LABファイルの内容

LABファイルには、音素ごとの開始時刻・終了時刻・音素名が記録されます。

各行の形式は次のとおりです。

```text
<開始時刻> <終了時刻> <音素>
```

時刻の単位は100ナノ秒です。

例えば、`10000000` は1秒を表します。

無音区間には `pau` が使用されます。

LABファイルには、採用した音声全体を対象とする音素の時刻情報が記録されます。

## 発音情報とLAB生成

LAB生成では、Takeの生成時に使用した発音情報をもとに、音声中の音素の位置を推定します。

JuliusやPocketSphinxが、文章から別の発音を自動的に選び直すわけではありません。

人名や造語などで読み上げが正しくない場合は、Voiceger Editorで発音を修正してからTakeを生成してください。

ただし、一般的でない音素の並びや、日本語の音声に無理やり英語のARPAbetを適用した場合などは、音声が生成できてもLABの時刻合わせに失敗することがあります。

発音編集については、[日本語の発音編集](japanese-pronunciation.md)と[英語の発音編集](arpabet.md)を参照してください。

## 日本語と英語が混在する場合

日本語と英語が混在するTakeでは、音声生成時に取得した情報を使ってLABを作成します。

そのため、**LABをONにしてからTakeを生成する必要があります。**

操作順は次のとおりです。

```text
LABをONにする
↓
Takeを生成する
↓
音声を確認する
↓
Takeを採用する
```

LABがOFFの状態で生成済みのTakeに対して、あとからLABをONにして採用しても、必要な情報がないためLABは生成できません。

その場合は、LABをONにした状態でTakeを再生成してください。

## LAB生成に失敗した場合

LABの生成に失敗しても、**採用した音声ファイルは保存されます。**

TXT出力が有効な場合、正常に保存できたTXTファイルも維持されます。

途中まで生成された不完全なLABファイルは残しません。

失敗した場合は、Voiceger EditorのStatusに理由が表示されます。

主な原因として、JuliusやPocketSphinxの不足、音響モデルの読み込み失敗、対応できない音素、時刻合わせの失敗などが考えられます。

## HTTP APIでのLAB出力

HTTP APIの `/synthesis` はWAV音声を返しますが、LABファイルは生成・保存しません。

LAB出力は、TUIでTakeを採用する際に使用する機能です。
