# 日本語の発音編集

Voiceger Editorでは、日本語の読みやアクセントを編集できます。

例えば、同じ「アメ」でも「雨」と「飴」ではアクセントが異なります。また、漢字の読みが意図したものと違っている場合にも、発音情報を修正できます。

ただし、実際に生成される音声が必ずしも指定どおりになるとは限りません。Previewで発音を確認しながら調整してください。

## 読みとアクセント

### 読みを修正する

同じ漢字でも、文脈や意図によって読み方が変わることがあります。

例えば、次の文章：

> この駅は人気がないのだ。

「人気」は、「にんき」と「ひとけ」のどちらとも読めます。

![「ニンキ」と自動変換されたBATCH ITEM](images/japanese-pronunciation/01-ninki-before.png)

自動変換で「ニンキ」と変換された場合でも、`EDIT PRONUNCIATION` 画面から「ヒトケ」に手動で変更できます。

![「ヒトケ」に修正したBATCH ITEM](images/japanese-pronunciation/02-hitoke-after.png)

具体的な操作方法は、[はじめての音声生成：アクセント句の区切りを変更](tui.md#4-アクセント句の区切りを変更)を参照してください。

### アクセントを修正する

日本語には、読みが同じでもアクセントが異なる言葉があります。

例えば「雨」と「飴」です。

| 単語 | 発音 |
|---|---|
| 雨 | `ア'メ` |
| 飴 | `アメ'` |

`'` はアクセントの位置を示す記号です。

アクセント位置を変更することで、同じ読みでも異なるアクセントを指定できます。

また、Voiceger Editorでは、1つのアクセント句に複数のアクセントを指定することもできます。

具体的な操作方法は、[はじめての音声生成：アクセント位置を変更](tui.md#3-アクセント位置を変更)を参照してください。

## 発音の表記ルール

### モーラとアクセント記号

日本語のアクセントは、モーラ単位で指定します。

モーラとは、日本語の音の長さを数える単位です。

例えば「ずんだもん」は、次の5モーラからなります。

```text
ズ・ン・ダ・モ・ン
```

通常の単一アクセントでは、アクセント記号 `'` を指定するモーラの直後に置きます。

```text
ズ'ンダモン
```

この例では、最初の「ズ」にアクセントを指定しています。

小さい「ャ」「ュ」「ョ」などは、直前の仮名と合わせて1モーラとして扱います。

例えば「キャ」は2文字で1モーラです。

```text
キャ'ク
```

長音記号「ー」は1モーラとして数えます。

ひらがなとカタカナのどちらでも入力できます。

### 複数のアクセントを指定する

1つのアクセント句の中で、音の高さが何度も上下する場合は、`[` と `]` を使用します。

- `[`：直前のモーラの後で音の高さを上げる
- `]`：直前のモーラの後で音の高さを下げる

例えば、「四国めたん」に2つの高い部分を指定する場合は、次のように入力できます。

```text
[シ]コク[メ]タン
```

この例では、「シ」と「メ」が高くなるように指定しています。

「メ」から「タン」まで高い状態を続けたい場合は、次のようにします。

```text
[シ]コク[メタン]
```

語の先頭に付ける `[` と、末尾に付ける `]` は、高い部分の始まりと終わりをわかりやすく示すためのものです。これらによって音の高さが余分に変化することはありません。

`EDIT PRONUNCIATION` では、`[` と `]` を直接入力・削除することで、アクセントの位置や数を変更できます。

### BATCH ITEMでの表示

`EDIT PRONUNCIATION` では、発音を続けて記述します。

一方、`BATCH ITEM` では、読みやすいようにモーラごとに空白を入れて表示します。

| EDIT PRONUNCIATION | BATCH ITEM |
|---|---|
| `[シ]コク[メ]タン` | `[シ] コ ク [メ] タ ン` |
| `[シ]コク[メタン]` | `[シ] コ ク [メ タ ン]` |
| `シ'コクメタン` | `[シ] コ ク メ タ ン` |

BATCH ITEMの空白は表示上の区切りです。実際のアクセント句が分割されているわけではありません。

複数アクセントを指定した発音行では、Left / Rightによるアクセント位置の変更はできません。Enterで`EDIT PRONUNCIATION`を開いて編集してください。

通常の単一アクセントでは、これまでどおりLeft / Rightでアクセント位置を変更できます。

### アクセント句の区切り

日本語の発音は、複数のアクセント句に分かれることがあります。

アクセント句とは、アクセントの動きを指定するまとまりです。1つのアクセント句に複数の高い部分を指定することもできます。

`EDIT PRONUNCIATION` では、アクセント句をスペースで区切ります。

```text
キョ'ーワ ア'メデスネ。
```

単一アクセントの句では `'` を使用します。複数アクセントの句では、`[` と `]` を使用します。

半角スペースと全角スペースの両方を使用できます。

**スペースは実際のアクセント句の区切りです。**

1つのアクセント句の中に複数の高い部分を指定するために、スペースを入力する必要はありません。

なお、アクセント句の区切りは、発話の間やリズムを直接指定するものではありません。

### 句読点

次の句読点を使用できます。

```text
。 、 ？ ！ …
```

半角の `. , ? !` を入力した場合は、対応する全角の句読点に変換されます。

## 編集画面の機能

### PreviewとApply

**Preview** は、編集中の発音を一時的に音声生成して確認する機能です。

Previewを実行しても、現在の発音情報は変更されません。また、通常のTakeも作成されません。

**Apply** は、編集した発音を確定する操作です。

発音を変更すると、既存のTakeはクリアされます。詳しくは[BATCH ITEM](batch-item.md)を参照してください。

### ClearとReset

**Clear** は、編集中の発音欄を空にします。

**Reset** は、編集画面を開いたときの発音に戻します。

どちらも、その操作だけでは現在の発音情報を変更しません。

Resetは、文章から発音を自動生成し直す操作ではありません。
