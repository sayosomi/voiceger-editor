# 英語の発音編集（ARPAbet）

Voiceger Editorでは、英語の発音を **ARPAbet** という音素表記で編集できます。

例えば、`very` の発音は次のように表します。

```text
V EH1 R IY0
```

ARPAbetは英単語のつづりではなく、どの音をどの順番で発音するかを表したものです。

ただし、実際に生成される音声が必ずしも指定どおりになるとは限りません。Previewで発音を確認しながら調整してください。

## ARPAbetの表記ルール

### 強勢（ストレス）

ARPAbetでは、母音の末尾につく数字で強勢を表します。

| 数字 | 意味 |
|---|---|
| `0` | 強勢なし |
| `1` | 第一強勢 |
| `2` | 第二強勢 |

例えば、次の発音では `EH` に第一強勢があり、`IY` には強勢がありません。

```text
V EH1 R IY0
```

子音には強勢の数字を付けません。

また、`BATCH ITEM` では第一強勢のある母音が `[]` で囲まれて表示されます。

```text
EN | very   V [EH1] R IY0
   | sweet  S W [IY1] T
```

この `[]` は画面上の表示であり、ARPAbetの入力には使用しません。

### 使用できる母音

Voiceger Editorでは、次の母音を使用できます。

| 音素 | おおよその発音例 |
|---|---|
| `AA` | hot の母音 |
| `AE` | cat の母音 |
| `AH` | cut、about などの母音 |
| `AO` | law の母音 |
| `AW` | now の母音 |
| `AY` | my の母音 |
| `EH` | bed の母音 |
| `ER` | bird の母音 |
| `EY` | say の母音 |
| `IH` | sit の母音 |
| `IY` | see の母音 |
| `OW` | go の母音 |
| `OY` | boy の母音 |
| `UH` | book の母音 |
| `UW` | food の母音 |

通常は、母音に `0`、`1`、`2` のいずれかを付けて入力します。

```text
AE1
IY0
OW1
```

例えば、`UW1` は使用できますが、数字のない `UW` は使用できません。

なお、既存の発音情報との互換性のため、`ER` と `IH` は数字のない形式も受け付けます。

### 使用できる子音

使用できる子音は次のとおりです。

```text
B   CH  D   DH  F   G   HH
JH  K   L   M   N   NG  P
R   S   SH  T   TH  V   W
Y   Z   ZH
```

いくつか、つづりだけでは分かりにくいものがあります。

| 音素 | おおよその発音例 |
|---|---|
| `CH` | chair の ch |
| `DH` | this の th |
| `HH` | hello の h |
| `JH` | judge の j |
| `NG` | sing の ng |
| `SH` | she の sh |
| `TH` | think の th |
| `ZH` | measure の中央の音 |

`TH` と `DH` はどちらも英語の `th` に使われますが、異なる音を表します。

### 単語の例

**sweet**

```text
S W IY1 T
```

**hello**

```text
HH AH0 L OW1
```

音素は半角スペースで区切って入力します。

## 英語の発音を編集する

Voiceger Editorでは、英語の発音を単語ごとに編集できます。

最初からすべてのARPAbetを入力する必要はありません。自動変換された発音情報をもとに、必要な部分だけ修正できます。

### 第一強勢を変更する

`BATCH ITEM` では、英単語の発音行でLeft / Rightキーを押すと、第一強勢の位置を移動できます。

例えば、`very` の場合は次のように変更できます。

**変更前**

```text
V EH1 R IY0
```

**変更後**

```text
V EH0 R IY1
```

これは操作の説明用の例であり、変更後の表記が `very` の自然な発音になるという意味ではありません。

第一強勢の移動は、移動先となる母音がある場合に限られます。

### 音素を直接編集する

英単語の発音行でEnterを押すと、`EDIT PRONUNCIATION` が開きます。

この画面では、選択した単語の音素を直接編集できます。

例えば、`sweet` なら次のように表示されます。

```text
EDIT PRONUNCIATION

Word
  sweet

▶ S W IY1 T
```

音素は半角スペースで区切って入力します。

編集した発音はPreviewで確認し、Applyで反映できます。

対応していない音素を入力した場合は、PreviewやApplyの際にエラーとなり、変更は反映されません。

### 編集画面の機能

**Preview** は、編集中の発音を一時的に音声生成して確認する機能です。現在の発音情報は変更されず、通常のTakeも作成されません。

**Apply** は、編集した発音を確定する操作です。

**Clear** は編集中の音素を空にし、**Reset** は編集画面を開いたときの音素に戻します。どちらも、その操作だけでは現在の発音情報を変更しません。

発音を変更すると既存のTakeはクリアされます。詳しくは[BATCH ITEM：Takeがクリアされる操作](batch-item.md#takeがクリアされる操作)を参照してください。

英語のみのCaptionや日英混在文のセクション操作については、[BATCH ITEM：セクションを追加する](batch-item.md#セクションを追加する)を参照してください。

調整した発音は英語ユーザー辞書にも登録できます。詳しくは[ユーザー辞書](dictionary.md)を参照してください。

## 日本語をARPAbetで近似する

ARPAbetは英語用の音素表記ですが、音素を組み合わせて日本語に近い音を作ることもできます。

**これは実用的な日本語発音のためではなく、遊び用途です。**

英語の音素を使った近似であり、日本語の発音を正確に再現できるものではありません。通常の日本語の読みやアクセントを編集したい場合は、[日本語の発音編集](japanese-pronunciation.md)を参照してください。

また、このような特殊な音素列では、**LAB出力がうまくいかない可能性が高いです**。LAB出力の仕組みや制限については、[LAB出力](lab.md)を参照してください。

以下の表は、各音に近づけるための目安です。実際の入力では、母音に強勢数字を付けてください。

### 五十音の目安

| 行 | あ段 | い段 | う段 | え段 | お段 |
|---|---|---|---|---|---|
| あ | `AA` | `IY` | `UW` | `EH` | `OW` |
| か | `K AA` | `K IY` | `K UW` | `K EH` | `K OW` |
| が | `G AA` | `G IY` | `G UW` | `G EH` | `G OW` |
| さ | `S AA` | `SH IY` | `S UW` | `S EH` | `S OW` |
| ざ | `Z AA` | `JH IY` | `Z UW` | `Z EH` | `Z OW` |
| た | `T AA` | `CH IY` | `T S UW` | `T EH` | `T OW` |
| だ | `D AA` | `JH IY` | `Z UW` | `D EH` | `D OW` |
| な | `N AA` | `N IY` | `N UW` | `N EH` | `N OW` |
| は | `HH AA` | `HH IY` | `F UW` | `HH EH` | `HH OW` |
| ば | `B AA` | `B IY` | `B UW` | `B EH` | `B OW` |
| ぱ | `P AA` | `P IY` | `P UW` | `P EH` | `P OW` |
| ま | `M AA` | `M IY` | `M UW` | `M EH` | `M OW` |
| や | `Y AA` | — | `Y UW` | — | `Y OW` |
| ら | `R AA` | `R IY` | `R UW` | `R EH` | `R OW` |
| わ | `W AA` | — | — | — | `OW` |

### 拗音

| 系列 | あ | う | お |
|---|---|---|---|
| きゃ・きゅ・きょ | `K Y AA` | `K Y UW` | `K Y OW` |
| ぎゃ・ぎゅ・ぎょ | `G Y AA` | `G Y UW` | `G Y OW` |
| しゃ・しゅ・しょ | `SH AA` | `SH UW` | `SH OW` |
| じゃ・じゅ・じょ | `JH AA` | `JH UW` | `JH OW` |
| ちゃ・ちゅ・ちょ | `CH AA` | `CH UW` | `CH OW` |
| にゃ・にゅ・にょ | `N Y AA` | `N Y UW` | `N Y OW` |
| ひゃ・ひゅ・ひょ | `HH Y AA` | `HH Y UW` | `HH Y OW` |
| みゃ・みゅ・みょ | `M Y AA` | `M Y UW` | `M Y OW` |
| りゃ・りゅ・りょ | `R Y AA` | `R Y UW` | `R Y OW` |

### 「ん」

日本語の「ん」は、後ろに続く音によって `N`、`M`、`NG` を使い分けると自然になることがあります。

| 日本語の音 | 目安 |
|---|---|
| んか・んが など | `NG` |
| んば・んぱ・んま など | `M` |
| その他 | `N` |

語末では `N` と `NG` の両方を試して、自然に聞こえる方を使用できます。

### 長音

日本語の長母音にそのまま対応する記号はありません。

| 日本語の音 | 近似の目安 |
|---|---|
| おー | `OW` |
| えー | `EY` |
| いー | `IY` |
| うー | `UW` |

### 外来音

| 系列 | あ | い | う | え | お |
|---|---|---|---|---|---|
| ファ・フィ・フ・フェ・フォ | `F AA` | `F IY` | `F UW` | `F EH` | `F OW` |
| ヴァ・ヴィ・ヴ・ヴェ・ヴォ | `V AA` | `V IY` | `V UW` | `V EH` | `V OW` |

そのほか、次のように近似できます。

| 系列 | イ | ウ |
|---|---|---|
| ティ・トゥ | `T IY` | `T UW` |
| ディ・ドゥ | `D IY` | `D UW` |

### 強勢を付ける

日本語をARPAbetで近似する場合も、母音には強勢数字を付けます。

例えば「ずんだもん」なら、次のように指定して試せます。

```text
Z UW1 N D AA0 M OW0 N
```

まず1か所に第一強勢 `1` を付け、それ以外を `0` にして試す方法です。

**英語の強勢と日本語のアクセントは異なります。** この数字で日本語のアクセントを正確に指定できるわけではありません。
