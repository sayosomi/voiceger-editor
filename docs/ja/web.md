# Web UIの使い方

Voiceger EditorのWeb UIでは、ブラウザから発音の編集、音声生成、Takeの管理、辞書や出力設定の変更ができます。

Webサーバーの起動と接続方法は[Web UIのセットアップ](web-setup.md)を参照してください。

## 1. 基本的な操作

接続すると「Batch List」が開きます。

基本的な流れは次のとおりです。

1. Captionを追加する
2. 発音を確認・編集する
3. Takeを生成する
4. 音声を聴き比べる
5. 気に入ったTakeを採用する

採用した音声は、Webサーバーを実行しているコンピューターのOutputフォルダへ保存されます。

## 2. Batch List

「＋ Caption追加」から文章を入力します。複数行を入力すると、空行を除き、1行ごとに1件のCaptionが追加されます。

一覧では次の操作ができます。

- **チェックボックス：** 一括生成の対象を切り替える
- **Captionを選択：** 個別の編集画面を開く
- **並べ替え：** ハンドルをドラッグして順序を変更する
- **削除：** 削除するCaptionを選択してまとめて削除する
- **一括生成：** 対象のCaptionの音声を順番に生成する

チェックを外してもCaptionは削除されません。個別の編集や生成は引き続き可能です。

## 3. Batch Item

Captionを選択すると、個別の編集画面が開きます。

ここではCaption、発音、Style、Speed、Take数を編集できます。画面下部から前後のCaptionへ移動することもできます。

**Captionと読み上げる文章は別々に管理されます。**

Captionだけを変更しても、調整済みの発音や既存のTakeは保持されます。一方、読み上げる文章や発音を変更すると、Take候補と採用状態がクリアされます。すでに保存した音声ファイルは削除されません。

「再解析」は、Captionをもとに発音を作り直す操作です。手動で調整した発音を失うため、確認してから実行してください。

## 4. 発音を編集する

「発音」欄から編集したい日本語・英語の発音を選択します。

### 日本語

日本語では、読み、アクセント句、ピッチアクセントを編集できます。

入力補助ボタンでアクセント記号や上昇・下降記号を挿入できます。

「Preview」で変更後の音声を確認し、「反映」で確定します。Previewだけでは発音は変更されません。

### 英語

英語ではARPAbetの音素と強勢を編集できます。

日本語と英語が混在する文章では、セクションごとに読み上げ文や発音を調整できます。「＋ 追加」からセクションを追加することもできます。

### 日本語からARPAbetへの変換

日本語の発音編集画面では「ARPAbetに変換」を使用できます。

変換後は英語の発音編集画面に直接切り替わり、音素や強勢を調整できます。

日本語の発音やアクセントを英語の音素・強勢に近似する機能のため、変換結果は確認・調整してください。変換できない入力ではエラーが表示され、元の発音は保持されます。

## 5. Takeを生成・採用する

「Preview」は、通常のTakeを追加せずに音声を確認する機能です。

Take数を指定し、生成ボタンを押すと複数の候補が作られます。

生成したTakeはそれぞれ再生できます。気に入ったTakeの「採用」を押すと、Outputフォルダに保存されます。複数のTakeを採用することもできます。

Takeごとの再生成ボタンでは、その未採用Takeだけを作り直します。

Takes欄の「⋯」からは「未採用Takeを再生成」と「候補をクリア」を使用できます。

採用済みTakeは未採用Takeの再生成対象になりません。保存済み音声ファイルも削除されません。

## 6. Batchファイル

Batch Listの「ファイル」から「保存」または「読み込む」を選びます。

Batchファイルには、Caption、発音情報、生成設定などが記録されます。

読み込み時に現在のBatchを置き換える場合は、確認画面が表示されます。

**Batchファイルには生成済みTakeの音声や採用状態は含まれません。** 作業セッションの完全なバックアップとしては使用できません。

## 7. 辞書

画面上部の「辞書」から、日本語・英語のユーザー辞書を管理できます。

単語の追加、編集、削除、検索、並べ替え、発音の編集やPreviewができます。

「管理」では、辞書ファイルのインポートとエクスポートを行います。

インポートでは、取り込む単語を確認・選択できます。エクスポートは、日本語・英語のZIPバックアップと、日本語のVOICEVOX JSON形式に対応しています。VOICEVOX形式への変換で情報が失われる場合は、警告を確認してください。

辞書ファイルの読み書きはサーバー側のOutputフォルダで行います。

## 8. 設定と保存先

画面上部の「設定」では、次の項目を変更できます。

- **音声生成：** Style、Speed
- **サンプリング：** Top K、Top P、Temperature
- **標準Take数：** Captionに個別指定がない場合のTake数
- **出力：** 保存先、ファイル名、WAV・FLAC・MP3、TXT・LAB

設定は変更時に自動保存されます。「保存済み」またはエラー表示を確認してください。

「設定値を初期化」では、音声生成・サンプリング・標準Take数・出力形式を初期値に戻します。Output保存先、ファイル名、既存のTakeや採用状態は保持されます。

MP3出力にはサーバー側のFFmpegが必要です。LAB出力には別途依存パッケージや外部ツールが必要です。

## 9. 接続と作業の終了

ページを再読み込みした場合、アクセストークンの再入力が必要です。サーバーと作業セッションが残っていれば再接続できます。

「設定」→「作業を終了」を実行すると、作業中のBatchと未保存のTake候補は破棄されます。

保存済み音声ファイルは残ります。

サーバーの停止方法などは[Web UIのセットアップ](web-setup.md)を参照してください。
