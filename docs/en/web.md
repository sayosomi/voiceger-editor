# Using the Web UI

Voiceger Editor's Web UI lets you edit pronunciation, generate and manage Takes, work with dictionaries, and change output settings from a browser.

For installation and connection instructions, see [Web UI Setup](web-setup.md).

The interface currently uses Japanese labels. This guide includes the labels you will see on screen.

## 1. Basic Workflow

After connecting, the Batch List opens.

The normal workflow is:

1. Add a Caption.
2. Review or edit its pronunciation.
3. Generate Takes.
4. Listen to the candidates.
5. Accept the Takes you want to save.

Accepted audio is saved in the Output directory on the computer running the Web server.

## 2. Batch List

Select **＋ Caption追加** (Add Captions) to enter text. Each non-empty line becomes a separate Caption.

You can use the list to:

- Include or exclude Captions from batch generation using checkboxes.
- Open a Caption for individual editing.
- Reorder Captions by dragging their handles in **並べ替え** (Reorder) mode.
- Select and delete Captions in **削除** (Delete) mode.
- Start generation using **一括生成** (Batch Generate).

Excluding a Caption does not delete it. You can still edit and generate it individually.

## 3. Batch Item

Select a Caption to open its editor.

You can edit its Caption text, spoken pronunciation, Style, Speed, and Take count. Navigation controls move between Captions.

**Caption text and spoken content are separate.**

Changing only the Caption preserves existing pronunciation and Takes. Changing spoken sections or pronunciation clears current Take candidates and acceptance markers, but previously saved audio files remain.

**再解析** (Reanalyze) rebuilds pronunciation from the Caption and discards manual pronunciation adjustments.

## 4. Pronunciation Editing

Select a pronunciation entry in the **発音** (Pronunciation) section.

### Japanese

Edit readings, accent phrases, and pitch-accent notation. Input-assist buttons insert accent, rise, fall, and spacing symbols.

Select **Preview** to audition a change without committing it. Select **反映** (Apply) to save the pronunciation edit.

### English and Mixed Text

Edit English ARPAbet phonemes and stress.

Mixed Japanese-English text can have separate spoken sections. Select a section to edit its spoken text, or use **＋ 追加** (Add) to create another section.

### Japanese-to-ARPAbet Conversion

From a Japanese pronunciation editor, select **ARPAbetに変換** (Convert to ARPAbet).

The editor switches directly to English pronunciation editing, where you can adjust phonemes and stress.

The conversion approximates Japanese pronunciation and pitch accent using English phonemes and stress. Review the result before synthesis. Unsupported input is rejected without replacing the original pronunciation.

## 5. Generate, Play, and Accept Takes

**Preview** auditions speech without creating a normal Take.

Choose the desired Take count, then generate candidates. Each Take has playback controls.

Select **採用** (Accept) to save a Take to the server's Output directory. Multiple Takes can be accepted.

An individual regeneration control replaces only the corresponding unaccepted Take.

The **⋯** menu provides **未採用Takeを再生成** (Regenerate Unaccepted Takes) and **候補をクリア** (Clear Candidates).

Accepted Takes are not regenerated by the unaccepted-Take operation, and previously saved audio files are preserved.

## 6. Batch Recipe Files

From Batch List, open **ファイル** (Files) and choose **保存** (Save) or **読み込む** (Load).

Recipe files contain Captions, pronunciation information, and generation settings.

Replacing the current Batch requires confirmation.

**Recipe files do not contain generated Take audio or acceptance status.** They are not complete session backups.

## 7. User Dictionaries

Open **辞書** (Dictionary) from the top navigation.

The Japanese and English dictionaries support adding, editing, deleting, searching, sorting, pronunciation editing, and previews.

Under **管理** (Manage), you can review and selectively import dictionary entries.

Export formats include a ZIP backup for Japanese and English entries and a Japanese VOICEVOX JSON export. Review any warning about information loss during export.

Dictionary file operations use the server's Output directory.

## 8. Settings and Output

Open **設定** (Settings) to configure:

- Style and Speed
- Top K, Top P, and Temperature
- Default Take count
- Output directory and filename template
- WAV, FLAC, or MP3 format
- Optional TXT and LAB files

Changes are saved automatically. Check the saved or error status after editing a setting.

**設定値を初期化** (Reset Settings) restores the defaults for synthesis, sampling, default Take count, and output format. It preserves the Output directory, filename template, existing Takes, and acceptance status.

MP3 output requires FFmpeg on the server. LAB output requires additional dependencies or external tools.

## 9. Reconnection and Shutdown

Reloading the browser requires re-entering the access token.

An existing session can be resumed while the server and session remain active.

Selecting **設定** (Settings) → **作業を終了** (End Session) discards the current Batch and temporary Take candidates.

Previously saved audio files remain on the server.

See [Web UI Setup](web-setup.md) for connection and shutdown instructions.
