# Voiceger Editor v0.1.1

Voiceger Editorは、ローカルにインストールしたVoicegerを使用する、キーボード操作中心の発音・音声合成エディターです。

v0.1.1では、複数のセリフを扱うワークフローの大幅な改善、発音編集機能の拡張、音声出力形式の追加、ユーザードキュメントの充実を行いました。

## 基本機能

Voiceger Editorはv0.1.0から次の機能を備えています。

- 日本語の発音・ピッチアクセント編集
- 英語のARPAbet発音記号・強勢編集
- 複数のTakeの生成、プレビュー、再生、採用
- 日本語・英語のユーザー辞書
- TXT・LABファイルのオプション出力
- Voicegerを音声合成エンジンとして使用するVOICEVOX互換形式のHTTP API

## v0.1.0からの主な変更点

### Batch編集・Take管理

- **BATCH LIST / BATCH ITEM**で複数のCaptionを管理できるようになりました。
- 複数行の文章を貼り付け、1行ずつ独立したCaptionとして追加できます。
- 対象のCaptionを選択し、順番にTakeを一括生成できます。
- Caption、発音情報、音声生成設定などをバッチファイルに保存・読み込みできます。
- CaptionごとにStyleとSpeedを個別設定できます。
- 1つのCaptionで複数のTakeを採用できるようになりました。採用済みのTakeを保持したまま未採用のTakeだけを再生成できます。
- 字幕用のCaptionと実際に読み上げる文章を別々に編集できます。

### 発音編集の改善

- **英語だけのCaption**に対応しました。Voicegerの英語モードを使用して音声を生成できます。
- 日本語と英語が混在する文章の自動判定・分割処理を改善しました。
- 日本語の1つのアクセント句に、複数のピッチの上昇・下降を指定できるようになりました。
- 日本語辞書でも複数のアクセントの山を持つ発音を扱えます。
- 英語の句読点を、Captionの文章とは独立して編集できます。
- 発音プレビューや英語の強勢位置の調整を改善しました。

### ユーザー辞書の改善

- 辞書一覧にソート・フィルター、数字キーによるジャンプを追加しました。
- 辞書一覧から単語の発音をプレビューできます。
- 一覧上で日本語のアクセントや英語の第一強勢を調整できます。
- 辞書の解析・保存処理を改善し操作中の応答性を向上させました。
- 日本語辞書と英語辞書をまとめて、1つのZIPファイルにバックアップできます。
- インポート時には既存の単語との差分を確認し、必要な単語だけを選択してマージできます。
- HTTP APIから英語辞書を操作できるようになりました。

### 音声出力・設定

- 採用したTakeをWAV・FLAC形式で保存できます。FFmpegを導入するとMP3形式でも保存できます。
- ファイル名のテンプレートを設定できます。
- Takeの保存、バッチファイルの書き出し、辞書のエクスポートにおいて、同一の出力ディレクトリを使うようになりました。出力ディレクトリの場所は設定から変更できます。
- 音声生成の進捗表示と処理中の操作制御を改善しました。

### TUIの操作性・安定性

- BATCH LIST、辞書一覧、Take候補で数字キーによる直接移動に対応しました。2桁以上の候補があるときは、数字入力後Enterを押してください。
- バックグラウンド生成、画面移動、キャンセル操作、Status表示を改善しました。
- 各種編集画面や確認画面の操作を統一・改善しました。
- 回帰テストを拡充しTUIの内部構造を整理しました。

- **スクリーンショット付きの日本語ユーザードキュメント**を新たに整備しました。

## インストール

Voiceger本体を別途インストールし、VoicegerのPython 3.9環境を有効にしてから、Voiceger Editorをインストールします。

```bash
python -m pip install "voiceger-editor[tui]==0.1.1"
```

インストール後、次のコマンドで確認できます。

```bash
voiceger-editor --version
voiceger-editor --check
```

追加機能に必要なパッケージや詳しいセットアップ方法は、[セットアップガイド](https://github.com/sayosomi/voiceger-editor/blob/main/docs/ja/setup.md)を参照してください。

## 対応環境と制限事項

- **対応Python：** 3.9
- **動作確認済みVoiceger revision：** `f77c1172baf1f490bb962f2d2acd01c852ef3464`
- **対応する文章：** 日本語、英語、日本語と英語が混在する文章
- **Windows：** パッケージのインストールとTUIの起動処理は自動テストで検証しています。ただし、物理Windows環境での実際の音声生成、対話的なTUI操作、LAB生成については十分な検証が完了していません。
- **HTTP API：** VOICEVOX Engine APIの一部に対応しています。完全な互換性を保証するものではありません。
- **Voiceger本体：** Voiceger本体、モデル、参照音声はVoiceger Editorに含まれていません。別途インストールが必要です。

v1.0に到達するまでは、操作方法やデータ形式などが変更される可能性があります。

## ライセンスと生成音声について

Voiceger Editorは非公式のツールであり、ソースコードにはMITライセンスが適用されます。

ただし、**MITライセンスが適用されるのはVoiceger Editorのコードのみです。**

Voiceger本体、モデル、参照音声、生成音声、その他の第三者の著作物などには適用されません。

Voicegerで生成した音声には、公式のVoicegerずんだもん音源利用規約が適用され、所定のクレジット表記が必要です。

[Voicegerずんだもん音源利用規約](https://zunko.jp/con_ongen_kiyaku.html)
