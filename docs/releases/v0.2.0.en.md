# Voiceger Editor v0.2.0

Voiceger Editor v0.2.0 introduces a **browser-based Web UI** alongside the existing terminal interface.

Run the Web server on a computer with Voiceger installed, then edit pronunciation, generate speech, and manage Takes from a browser on another computer or smartphone.

## Highlights

### New Web UI

- Batch editing and generation
- Japanese, English, and mixed-language pronunciation editing
- Take generation, playback, and acceptance
- Japanese and English user dictionaries
- Voice generation and output settings

The Web UI runs locally and supports access from other devices on the same tailnet through Tailscale Serve. Access requires an authentication token.

### Japanese pronunciation to ARPAbet conversion

Convert Japanese pronunciation and pitch-accent information into approximate ARPAbet phonemes and stress patterns directly from the pronunciation editor.

This feature is available in both the TUI and Web UI. Conversion results may require manual adjustment.

### Shared functionality improvements

Improvements to pronunciation editing, dictionary management, synthesis, and Take handling provide a more consistent set of capabilities across the TUI and Web UI.

## Getting started

See the [Web UI Setup Guide](https://github.com/sayosomi/voiceger-editor/blob/main/docs/en/web-setup.md) and [Web UI Guide](https://github.com/sayosomi/voiceger-editor/blob/main/docs/en/web.md).

## Compatibility and limitations

- Python 3.9 is supported. Voiceger, its models, and reference audio must be installed separately.
- The Web server has been tested on macOS, with remote browser access tested on Android through Tailscale Serve.
- Complete Web workflows on Linux and Windows, and physical Windows speech synthesis, have not been fully verified.
- Temporary Takes and active Batch sessions are lost when the Web server restarts or the session ends. Previously saved audio files remain available.
- MP3 output requires FFmpeg. LAB output requires additional dependencies or external tools.
- The VOICEVOX-compatible HTTP API implements only part of the VOICEVOX Engine API.
