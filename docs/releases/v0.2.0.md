# Voiceger Editor v0.2.0

Voiceger Editor v0.2.0では、**ブラウザから操作できるWeb UI**を新たに追加しました。

従来のTUIに加え、VoicegerをインストールしたコンピューターでWebサーバーを起動し、別のPCやスマートフォンから発音編集や音声生成を行えるようになりました。

## 主な変更点

### Web UIを追加

- Batchの作成・編集と一括音声生成
- 日本語・英語・日英混在の発音編集
- Takeの生成・再生・採用
- 日本語・英語のユーザー辞書管理
- Style、Speed、出力形式、保存先などの設定

Web UIはローカルで動作し、Tailscale Serveを使用することでtailnet内の別端末からアクセスできます。接続にはアクセストークンが必要です。

### 日本語の発音をARPAbetへ変換

日本語の発音編集画面から、読みとアクセントをARPAbetに変換できるようになりました。TUIとWeb UIの両方で使用できます。

変換は英語の音素と強勢による近似のため、必要に応じて結果を調整してください。

### TUIと共通機能の改善

発音編集、辞書操作、音声生成、Take管理に関する共通処理を改善し、TUIとWeb UIで主要機能を利用できるようにしました。

## 対応環境と制限事項

- 対応Pythonは3.9です。Voiceger本体、モデル、参照音声は別途必要です。
- WebサーバーはmacOS、リモート操作はAndroidとTailscale Serveの組み合わせで実機確認しています。
- Linux・WindowsでのWebサーバー動作や、物理Windows環境での音声生成などは、十分な実機検証を行っていません。
- Webサーバーの再起動やセッション終了によって、一時的なTake候補や作業中のBatchは失われます。保存済みの音声ファイルは保持されます。
- MP3出力にはFFmpeg、LAB出力には追加の依存パッケージや外部ツールが必要です。
- VOICEVOX互換HTTP APIは、VOICEVOX Engineのすべての機能に対応するものではありません。
